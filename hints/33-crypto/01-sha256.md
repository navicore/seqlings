# Hint: SHA-256 Hashing

`crypto.sha256` is a pure function — same input, same output, always 64 hex chars. `hash-message` is a one-line wrapper. For `same-hash?`, hash both inputs and compare with `=`.

## Solution

```seq
: hash-message ( String -- String )
    crypto.sha256
;

: same-hash? ( String String -- Bool )
    crypto.sha256
    swap crypto.sha256
    =
;
```

## How `same-hash?` Works

Stack starts `( a b )`. The first `crypto.sha256` hashes the top (`b`), giving `( a hash-of-b )`. `swap` brings `a` to the top: `( hash-of-b a )`. The second `crypto.sha256` produces `( hash-of-b hash-of-a )`. `=` compares them.

Since SHA-256 is deterministic, equal inputs always produce equal hashes.
