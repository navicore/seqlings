# Hint: Base64 Encoding

Both words are thin wrappers over the `encoding.*` builtins. `base64-encode` takes a String and returns a String. `base64-decode` returns a String *and* a success Bool on top — the test consumes that Bool with `test.assert`.

## Solution

```seq
: encode-message ( String -- String )
    encoding.base64-encode
;

: decode-message ( String -- String Bool )
    encoding.base64-decode
;
```
