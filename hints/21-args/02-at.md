# Hint: Reading an Argument

## Solution

```seq
: arg-empty? ( Int -- Bool )
    args.at string.empty?
;
```

`args.at` consumes the index, pushes the string. `string.empty?`
consumes the string, pushes the Bool.

## The test only checks your word runs

The real "missing vs explicitly empty" behaviour needs real args,
which `seqc test` can't provide. Run the shebang script in the
exercise header to see both cases.
