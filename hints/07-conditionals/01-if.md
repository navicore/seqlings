# Hint: The if Combinator

`if` is a word that takes a Bool and two quotations. A quotation is just code wrapped in square brackets — chapter 10 goes deeper on quotations.

The Bool decides which quotation runs:
- True → first quotation
- False → second quotation

Whichever runs, the stack shape it produces should match the other.

Position on the stack: the Bool is below both quotations. The order at the call site reads naturally — `condition [ then ] [ else ] if`.
